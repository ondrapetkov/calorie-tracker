# From AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Log a one-off food from an AI's estimate by copying a prompt and pasting the answer, optionally storing it as a food.

**Architecture:** A pure reader (`src/domain/aiEstimate.ts`) finds the answer's final block and reuses `parseNutritionText` for the nutrient lines. A repo method logs the estimate as a food-less entry (or saves a custom food first and logs from it), marking it `estimate: 'ai'`. The add flow gets an `ai` view (copy, paste, check) and a store-it dialog; the diary row shows the ✨ marker.

**Tech Stack:** React 19, Dexie, Tailwind, Vitest + fake-indexeddb, Playwright (Firefox + WebKit).

**Spec:** `docs/superpowers/specs/2026-11-21-from-ai-design.md`

## Global Constraints

- Prompt text exactly as in the spec (export it as `AI_PROMPT`).
- Read only from the last line starting `Name:` to the end. Required: Name, Weight, Energy, Protein, Carbohydrates, Fat. Optional: Sugars, Fibre, Salt.
- Entry field `estimate?: 'ai'`; food-less entry has `foodId: null, mealId: null`.
- Stored food: `source: 'custom'`, `basis: 'g'`, per 100 g = totals × 100 / grams, `defaultServingG` = grams, `defaultServingLabel: '1 portion'`.
- Copy: button "Copy prompt" → "✓ Prompt copied"; "Paste the answer"; check screen button "Add to diary"; dialog title `Save "<name>" as a food?`, buttons "Just this entry" (primary) and "Save as a food too"; diary row prefix `✨ AI estimate · `.
- The From AI button shows only in the diary's add flow (log mode).

## Review Focus

- AI prose before the block mentions "about 800–900 kcal": the block's Energy must win. (Task 1 test.)
- Decimal comma and "mg" salt in the block ("Salt: 2,1 g", "Salt: 850 mg"). (Task 1 test.)
- Clipboard write blocked (Firefox permissions, insecure context): the prompt is shown in a box to copy by hand. (Task 3.)
- Changing the amount on the check screen scales the totals; an amount of 0 or blank can't be added. (Task 3 e2e.)
- Editing a food-less AI entry's amount later in Edit entry rescales it like any food entry. (Task 2 test via `updateEntry`.)
